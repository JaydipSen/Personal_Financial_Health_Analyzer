# 💰 Personal Financial Health Analyzer

An interactive personal finance dashboard developed using Python and Streamlit. The application enables users to analyze their financial health through income, expenses, savings, debt, assets, liabilities, net worth, and investment projections.

This project is designed particularly for **financial literacy workshops, undergraduate students, and personal finance education**.

## Features

### Financial Overview
- Monthly income and expenditure analysis
- Monthly surplus or deficit calculation
- Financial health score
- Net-worth calculation

### Expense Analytics
- Expense category comparison
- Expense distribution pie chart
- Expense treemap
- Pareto analysis of spending

### Financial Ratios
- Savings rate
- Expense-to-income ratio
- Debt repayment-to-income ratio
- Comparison with illustrative financial benchmarks

### Savings and Emergency Fund
- Savings progress indicator
- Savings rate gauge
- Emergency fund coverage
- Emergency fund target and gap analysis

### Debt Analytics
- Total outstanding debt
- Debt-to-asset ratio
- Loan composition visualization
- Debt category comparison

### Asset and Net Worth Analysis
- Asset allocation charts
- Asset treemap
- Liability composition
- Personal balance sheet visualization
- Net-worth analysis

### Investment Planning
- Compound investment projection
- Contributions versus investment growth
- Portfolio value projection over time

### Scenario Analysis
- Simulate income increases or decreases
- Simulate expense reductions or increases
- Compare current and hypothetical financial situations

### Export
- Download financial summary as CSV
- Download expense breakdown as CSV
